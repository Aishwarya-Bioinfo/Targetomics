Supported Input Formats

  • CSV / TSV / TXT / XLSX
  • Human transcriptomic expression matrices
  • Normalized counts / TPM / FPKM / raw counts
  • First column should contain gene names
  • Remaining columns should contain numeric expression values

Currently Not Supported

  • GEO metadata-only files
  • Supplementary pathway tables
  • Non-human datasets
  • DEG summary tables without expression matrices
